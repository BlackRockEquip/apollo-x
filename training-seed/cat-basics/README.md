# Cat Basics courses (Tech Training seed)

The seven courses from the Service Tech Training prototype, imported in one click from
Tech Training > Course manager ("Cat Basics courses ready to import").

- `courses.json` - all seven courses (chapters, lessons, pages of text).
- `covers/<course>.jpg` - course cover images.
- `img/<course>.json` - diagram packs: which image goes on which page, images as data URLs.

Diagram packs included: drivetrain-a, fde-2, hyd-2, hyd-3.
Not included (too large to copy across in this build): drivetrain-b, fde-1, hyd-1. Those three courses
import as text. To add their diagrams later, drop the pack file here as `img/<course>.json` before
importing, or open the course in the Course manager > Settings > "Add diagrams (image pack .json)".

The material is Caterpillar's training content: it stays behind the company's Flo X sign-in.
